# Description

Kink Jars for WordPress embeds the Kink Jars questionnaire with one shortcode, `[kink_jars]`. Visitors pick a colour or a pride palette, fill 35 jars from 1 to 5 or mark them Not for me, save a poster as a PNG, and can swap codes with a partner to see only the jars they're both into.

The plugin stores nothing on your site. Everything stays in the visitor's browser. It's distributed on GitHub, not the WordPress.org directory.
