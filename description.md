# Description

Kinky Jars is a one-page, adults-only questionnaire. You pick a colour, fill a row of jars from 1 (a little) to 5 (overflowing), cross out any that are a firm no, optionally dress the jars in a pride flag's colours, and save the lot as a PNG to keep or share. Swap a short code with a partner and it shows the jars you're both into, and nothing else.

It's plain HTML, CSS and JavaScript in a single file. No build step, no packages, no server side. Names and answers stay in your browser's local storage, the fonts are bundled so the page talks to no other site, and there's an easy-read font option for people who find the default type hard going.

Tests: a dependency-free logic suite, plus a real-browser smoke suite (Playwright) that GitHub Actions runs on every push.
