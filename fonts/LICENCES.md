# Font licences

All five files are the Latin subset as served by Google Fonts, bundled here so the page makes no third-party requests. Each family should be under the SIL Open Font Licence 1.1 (https://openfontlicense.org), which allows bundling with the licence notice kept. See the caveat below.

| File | Family | Source |
| --- | --- | --- |
| `oswald.woff2` | Oswald (variable) | https://fonts.google.com/specimen/Oswald |
| `nunito.woff2` | Nunito (variable) | https://fonts.google.com/specimen/Nunito |
| `permanent-marker.woff2` | Permanent Marker | https://fonts.google.com/specimen/Permanent+Marker |
| `atkinson-hyperlegible-400.woff2`, `-700.woff2` | Atkinson Hyperlegible, by the Braille Institute | https://fonts.google.com/specimen/Atkinson+Hyperlegible |

I haven't verified the licences against upstream in this pass: "OFL 1.1" is what I believe Google Fonts lists for all four families, from memory. The Google subsets don't ship a licence file either. Before redistributing commercially, pull the OFL.txt for each family from its upstream repository, confirm it, and add the texts here.
