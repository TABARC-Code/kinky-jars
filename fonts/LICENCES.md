# Font licences

All five files are the Latin subsets served by Google Fonts, bundled here so the page makes no third-party requests. The licence texts sit in `fonts/licences/`, copied from the `google/fonts` repository on GitHub (the `main` branch, 11 October 2026).

| File | Family | Licence | Licence text |
| --- | --- | --- | --- |
| `oswald.woff2` | Oswald (variable) | SIL Open Font Licence 1.1 | `licences/oswald-OFL.txt` |
| `nunito.woff2` | Nunito (variable) | SIL Open Font Licence 1.1 | `licences/nunito-OFL.txt` |
| `atkinson-hyperlegible-400.woff2`, `-700.woff2` | Atkinson Hyperlegible, Braille Institute of America | SIL Open Font Licence 1.1 | `licences/atkinson-hyperlegible-OFL.txt` |
| `permanent-marker.woff2` | Permanent Marker | Apache Licence 2.0 | `licences/permanent-marker-Apache-2.0.txt` |

An earlier version of this file guessed that all four were OFL. Permanent Marker isn't; it's Apache 2.0. Both licences allow bundling and redistribution as long as the licence text travels with the font, which is why the texts are here now.
