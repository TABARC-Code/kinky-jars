# Font licences

All five files are the Latin subset as served by Google Fonts, bundled here so the page makes no third-party requests. Each family is licensed under the SIL Open Font Licence 1.1 (https://openfontlicense.org), which allows bundling and redistribution with the licence notice kept.

| File | Family | Source |
| --- | --- | --- |
| `oswald.woff2` | Oswald (variable) | https://fonts.google.com/specimen/Oswald |
| `nunito.woff2` | Nunito (variable) | https://fonts.google.com/specimen/Nunito |
| `permanent-marker.woff2` | Permanent Marker | https://fonts.google.com/specimen/Permanent+Marker |
| `atkinson-hyperlegible-400.woff2`, `-700.woff2` | Atkinson Hyperlegible, by the Braille Institute | https://fonts.google.com/specimen/Atkinson+Hyperlegible |

I checked the licence from each specimen page's own licence note, not from a copy of the licence text shipped inside the font files, because the Google subsets don't carry one. If you redistribute this repo commercially, pull the OFL.txt for each family from its upstream repository and add it here.
